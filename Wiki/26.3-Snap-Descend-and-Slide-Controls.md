## 2. Step-by-Step Player Workflow

```
[ Player On Ladder ]
         |
         +---> Looking Straight / Up (Pitch <= 45.0 deg)
         |         |
         |         +---> Press Shift/Sneak ---> Complete Anchor (yd = 0.0 b/t)
         |         +---> Descending Down    ---> Standard Scaling: yd * (DESCEND_SPEED / 100)
         |
         +---> Tilt Camera Sharply Down (Pitch > 45.0 deg)
                   |
                   v
         [ Check Sneak Key Status ]
                   |
           [ NOT Sneaking ]
                   v
         [ SNAP DESCEND TRIGGERED ]
         yd = -0.4 blocks/tick (-8.0 m/s)
                   |
                   +---> Release Camera / Hold Shift ---> Immediate Safety Halt
                   +---> Reach Base Block           ---> Smooth Floor Transition
```

1. **Initiate Slide**: Look downwards toward the base of the ladder until your camera crosshair pitches past $45^\circ$ downward.
2. **High-Speed Descent**: The instant the threshold is crossed, downward velocity is overridden to $-0.4\text{ b/t}$ ($-8.0\text{ m/s}$), allowing rapid clearance of multi-dozen-block vertical shafts.
3. **Emergency Stop (Cling)**: Press and hold `Shift` (Sneak) at any time during descent to instantly cancel the slide and anchor safely in place.
4. **Controlled Descent**: If you want to descend at a controlled pace, keep your pitch angle shallower than $45^\circ$; descent speed will then respect `ladderspeed.descend_speed`.

## 3. Mathematical Vector Transformations & Safety Equations

### Pitch Angle Condition
Player pitch in Minecraft is defined such that straight ahead is $0^\circ$, looking straight up is $-90^\circ$, and looking straight down is $+90^\circ$:

$$\text{Snap Trigger Active} \iff \theta_{\text{pitch}} > 45.0^\circ \quad \land \quad \neg \text{isSuppressingSlide}$$

### Downward Velocity Equations
1. **Snap Descend Mode** (Pitch $> 45.0^\circ$, Sneak not held):
   $$v_y = -0.4 \quad (\text{blocks/tick}) = -8.0 \quad (\text{blocks/second})$$

2. **Controlled Descend Mode** (Pitch $\le 45.0^\circ$ and descending):
   $$v_y' = v_{\text{vanilla}} \times \frac{\text{DESCEND\_SPEED}}{100}$$

3. **Sneak Cling Mode** (Sneak key active):
   $$v_y = 0.0 \quad (\text{stationary hold})$$

### Downward Speed Comparison Matrix

| Movement State | Pitch Angle | Sneaking? | Downward Velocity ($v_y$) | Downward Speed ($S_y$) |
| :--- | :--- | :--- | :--- | :--- |
| **Vanilla Standard Slide** | Any | No | $-0.15$ to $-0.20\text{ b/t}$ | $-3.0$ to $-4.0\text{ m/s}$ |
| **Snap Descend (Modded)** | **$> 45.0^\circ$** | **No** | **$-0.40\text{ b/t}$** | **$-8.00\text{ m/s}$** |
| **Controlled Descend (100%)** | $\le 45.0^\circ$ | No | $-0.20\text{ b/t}$ | $-4.00\text{ m/s}$ |
| **Controlled Descend (200%)** | $\le 45.0^\circ$ | No | $-0.40\text{ b/t}$ | $-8.00\text{ m/s}$ |
| **Sneak Cling Hold** | Any | **Yes** | **$0.00\text{ b/t}$** | **$0.00\text{ m/s}$** |

## 7. Developer & Mixin Hooks

### Method Injection: `handleOnClimbable`
In `net.instantgratification.ladderspeed.mixin.LivingEntityMixin`:

```java
@Inject(method = "handleOnClimbable(Lnet/minecraft/world/phys/Vec3;)Lnet/minecraft/world/phys/Vec3;", at = @At("RETURN"), cancellable = true)
```

### Logic Implementation: `ClimbingLogic.modifyClimbVelocity`
```java
else if (yd < 0.0) {
    boolean snapDescend = DynamicGameRuleManager.getBoolean(entity.level(), LadderSpeedRules.SNAP_DESCEND);
    
    // Snap descend triggers if looking down sharply (> 45 pitch) and not sneaking (suppressing slide)
    if (snapDescend && entity.getXRot() > 45.0f && !entity.isSuppressingSlidingDownLadder()) {
        yd = -0.4; // Force slide down significantly faster
    } else {
        int descendRule = DynamicGameRuleManager.getInt(entity.level(), LadderSpeedRules.DESCEND_SPEED);
        if (descendRule <= 0) descendRule = 100;
        float descendSpeedMultiplier = descendRule / 100.0f;
        yd *= descendSpeedMultiplier;
    }
}
```
